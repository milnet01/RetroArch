## Summary
This patch changes the menu code that every RetroArch menu style shares. Most of it adds safety checks so the menu does not crash when a list or setting is missing. It also removes four unused menu-driver hooks and fixes a loop that builds number pickers so it cannot run forever. It adds a small helper that remembers which Content Downloader files finished. That helper is needed because a downloaded archive is deleted after unpacking, so its name is no longer on disk to check. Many of the new comments explain why a check exists, but several point at line numbers, functions or files that are not there.
